# מענה חכם בוואטסאפ — Landing Page

Static Hebrew RTL landing page for the WhatsApp Business auto-reply offer.

## Local preview
Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Deploy
Any static host works (GitHub Pages, Netlify, Cloudflare Pages, Vercel static).
Point the site root at this folder (`index.html`).
